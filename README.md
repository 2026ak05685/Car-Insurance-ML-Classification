# Car Insurance Claim Prediction — Machine Learning Classification

## Project Overview

This project focuses on predicting car insurance claims using different machine learning classification algorithms.

The objective is to implement and compare five classification models on the same dataset, evaluate their performance using multiple metrics, and deploy an interactive web application using Streamlit.

**Course:** Machine Learning  
**Programme:** M.Tech in Artificial Intelligence and Machine Learning  
**Institution:** BITS Pilani WILP

## 1. Problem Statement

Insurance claim prediction is a binary classification problem in which the objective is to predict whether a customer will make a car insurance claim based on their demographic information, driving history, and vehicle-related attributes.

The project aims to compare different machine learning algorithms and identify the model that performs best on the selected dataset.

## 2. Dataset Description

**Dataset:** Car Insurance Claim  
**Source:** [Kaggle — Car Insurance Data](https://www.kaggle.com/datasets/sagnik1511/car-insurance-data)

| Attribute | Description |
|---|---|
| Number of samples | 10,000 |
| Input features | 17 |
| Target variable | OUTCOME |
| Problem type | Binary Classification |

The dataset includes features such as age, gender, driving experience, education, income, credit score, vehicle ownership, annual mileage, speeding violations, DUIs, and previous accidents.

**Target variable:**
- `0`: No insurance claim
- `1`: Insurance claim

## 3. Machine Learning Models

Five classification algorithms will be implemented:

1. Logistic Regression
2. Decision Tree Classifier
3. K-Nearest Neighbors (KNN)
4. Naive Bayes Classifier
5. Support Vector Machine (SVM)

All models will be trained and evaluated using the same dataset and train-test split for a fair comparison.

## 4. Evaluation Metrics

The performance of each model will be evaluated using:

- Accuracy
- Area Under the ROC Curve (AUC)
- Precision
- Recall
- F1 Score
- Matthews Correlation Coefficient (MCC)
